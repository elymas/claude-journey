## 1. 목표와 범위

‘밤의 숲에서 퀘스트를 선택한다’는 분위기를 유지하면서 원본 전체 지도 화면을 재현한다. 핵심은 금빛 명조 제목, 푸른 페어리 대사창, 세 ACT로 구분된 세로형 주차 목록, 떠오르는 포자다.

이번 산출물은 구현 전 설계 패키지다. 지도 화면의 8개 주차 링크와 잠긴 최종 목표를 대상으로 한다. 연결된 개별 주차 페이지의 내부 화면은 조사하지 않았다. 원본 상단의 제목 메뉴·Translate·Share·Sign in은 Claude 서비스의 호스트 UI이며, 독립 클론의 기본 재현 범위는 그 아래 Artifact 콘텐츠로 정한다. 호스트 UI까지 필요한 경우 별도 셸로 추가한다.

## 2. 화면 구조

```text
화면 전체: 고정된 어두운 숲 그라데이션 + 포자 Canvas
└─ main: 최대 680px, 좌우 padding 20px, 중앙 정렬
   ├─ QuestHeader
   │  ├─ SEASON 1 · 8 WEEKS
   │  ├─ 클로드 정복 퀘스트
   │  ├─ 점등된 막대 8개
   │  └─ 8 / 8 주차 개방
   ├─ FairyDialogue
   │  ├─ 우측 상단에 떠 있는 페어리
   │  └─ 페어리 이름표 + 두 줄 안내 + 깜박이는 ▼
   ├─ ActSection I   장비를 갖춘다      W1–2
   │  └─ QuestCard × 2
   ├─ ActSection II  시종을 만든다      W3–5
   │  └─ QuestCard × 3
   ├─ ActSection III 부대를 만든다      W6–8
   │  ├─ QuestCard × 3
   │  └─ LockedFinalQuest
   └─ CreditsFooter
```

전체는 단일 열 문서 스크롤이다. `main`의 680px은 패딩을 포함하므로, 넓은 화면의 실제 카드 폭은 최대 640px이다. 대사창의 ▼는 원본에서 버튼이 아닌 장식으로 확인된다.

주차 카드 전체가 링크다. 왼쪽 숫자, 가운데 제목과 `WEEK NN · 장소`, 오른쪽 `입장 ▶`로 구성한다. 실제 원본 링크는 [quests.json](quests.json)에 저장했다. 클론 1차 구현에서는 이 링크를 그대로 사용한다. 별도의 주차별 로컬 라우트는 해당 페이지를 구현할 때 연결한다.

최종 카드는 `◆`, `[메인] 클로드로 AI Agent 구축해서 현실로 돌아가기`, `최종 목표 · LV 부족`, `잠김`을 표시한다. 링크가 없는 정적 항목으로 만든다. 현재 원본은 8개 주차가 모두 개방되어 있으며, 막대는 학습 완료율이 아니라 개방 수를 나타낸다. 레벨 계산이나 잠금 해제 규칙은 확인되지 않았다.

## 5. 반응형

원본의 콘텐츠 브레이크포인트는 `max-width:520px`다. 별도의 태블릿 다열 배치는 없다.

| 항목 | 521px 이상 | 520px 이하 |
| --- | --- | --- |
| main 상단 padding | 56px | 40px |
| 카드 열 | 숫자 / 본문 / 입장 | 숫자 / 본문 |
| 입장 표시 | 우측 열 | 본문 아래, 두 번째 열에 좌측 정렬 |
| 카드 padding | 16px 18px | 14px 14px |
| 카드 간격 | 16px | 12px |
| 카드 제목 | 19px | 17px |
| 대사 | 17px | 16px |
| 페어리 | 76px, top -58px | 60px, top -48px |

한글에는 `word-break:keep-all; overflow-wrap:break-word`를 적용한다. 390px 화면에서는 제목이 최소 크기 36px으로 표시되고, 입장 표시가 카드 본문 아래로 내려가는 것을 Aside에서 확인했다. 320px에서 제목이 줄바꿈되면 높이를 자연스럽게 늘린다.

## 6. 상태와 모션

아래 스타일·애니메이션 값은 원본 소스에서 확인했다. Hover와 키보드 상태는 구현 후 실제 입력으로 검수한다.

| 대상 | 동작 |
| --- | --- |
| 일반 카드 | 배경 `rgba(17,28,22,.55)` |
| Hover | 배경 `rgba(26,42,33,.85)`, 테두리 강화, 오른쪽 4px 이동, 제목 금빛 |
| 전환 | 배경·테두리 .15초, 이동 .12초 |
| 키보드 포커스 | sigil 색 2px outline, offset 3px |
| 최종 목표 | ember 강조, 전체 opacity .75, 약한 주황 배경, 클릭 없음 |
| 메인 제목 | 5.5초 ease-in-out, opacity .86↔1 반복 |
| 페어리 | 5.2초 ease-in-out, 이동·회전 반복 |
| 대사창 ▼ | 1.15초 steps(2,end), opacity 1↔.12 |
| 배경 포자 | Canvas 2D, 46개, 느린 상승·좌우 흔들림·투명도 변화 |

포자 Canvas는 `position:fixed; inset:0; pointer-events:none; z-index:0`이며 본문은 z-index 1이다. DPR은 최대 2로 제한하고 resize 시 크기를 갱신한다. 원본은 고정 시드 `20260921`로 입자를 배치한다. `prefers-reduced-motion:reduce`에서는 CSS 모션을 끄고 포자를 정적으로 한 번 그린다.

페어리는 공개 HTML에 포함된 WebP 이미지다. 재현용으로 [fairy.webp](assets/fairy.webp)를 분리했다. 별도 이미지 생성은 필요하지 않다.

## 7. 구현 구조 제안

이 절은 원본의 기술 스택을 단정한 것이 아닌 클론 구현안이다. 현재 작업 디렉터리에 애플리케이션 코드가 없어, 시작 구성을 제안한다.

React + TypeScript + Vite와 일반 CSS로 충분하다. 서버·인증·데이터베이스 없이 정적 배포가 가능하다. 콘텐츠와 링크는 JSON으로 관리하고 전체 개방 수는 데이터에서 계산한다.

```text
src/
  App.tsx
  components/
    QuestHeader.tsx
    FairyDialogue.tsx
    ActSection.tsx
    QuestCard.tsx
    CreditsFooter.tsx
    SporeBackground.tsx
  data/quests.json
  styles/quest-map.css
public/assets/fairy.webp
```

`QuestMap → QuestHeader + FairyDialogue + ActSection[] + CreditsFooter`로 조합하고 `SporeBackground`는 배경 레이어로 둔다. `QuestCard`는 주차·제목·장소·테마·링크·잠금 상태를 받는다. `SporeBackground`는 마운트 시 Canvas를 초기화하고 언마운트 시 RAF와 resize 리스너를 정리한다.

주차는 `<ol><li><a>`로 표현한다. 최종 항목은 `<li>` 내부 정적 콘텐츠로 표시한다. 페어리·포자·장식 막대·화살표는 스크린리더에서 숨기고, 개방 수는 텍스트로 제공한다. 링크는 Enter로 열리고 카드 전체에 포커스가 보여야 한다. 푸터는 원본 표기를 유지한다.

## 8. 구현 순서와 완료 기준

1. JSON으로 헤더·ACT 3개·8개 링크·잠금 항목·푸터를 렌더링한다.
2. 원본 토큰과 폰트, 최대 폭, 제목·카드 간격을 맞춘다.
3. 대사창 발광과 페어리 에셋을 적용한다.
4. 520px 이하 카드 재배치와 긴 제목 줄바꿈을 맞춘다.
5. 포자·제목·페어리 모션과 reduced-motion 처리를 구현한다.
6. 데스크톱·모바일 화면과 입력 상태를 검수한다.

완료 검수 항목:

- 1440px·900px·390px·320px에서 가로 스크롤 없이 전체 콘텐츠가 보인다.
- 최대 카드 폭 640px, 주차 순서 1–8, ACT 구분 2/3/3이 원본과 같다.
- 8개 입장 링크가 JSON의 원본 목적지와 일치한다.
- 개방 막대 8개가 점등되고 `8 / 8 주차 개방`이 표시된다.
- 잠긴 최종 항목은 클릭·탭 이동 대상이 되지 않는다.
- Hover·Tab 포커스·Enter 탐색을 실제 브라우저에서 확인한다.
- 모바일에서 입장 표시가 본문 아래에 있고 긴 제목이 다른 요소를 밀어내지 않는다.
- reduced-motion에서 반복 애니메이션이 멈추고 화면 내용은 유지된다.
- 호스트 툴바를 제외한 동일한 콘텐츠 영역끼리 스크린샷을 비교한다. 입자와 반복 애니메이션은 고정한 후 정렬·폰트·간격을 평가한다.

### 잠금 항목 추가 조사

사용자 요청으로 공개 HTML의 최종 항목과 애플리케이션 스크립트를 추가 확인했다. 최종 항목은 `<div class="quest main">`으로 작성되어 있으며 `href`, 클릭 핸들러, 부록 본문이 없다. 콘텐츠의 Artifact 링크는 공개된 8개 주차 링크뿐이다. 자체 애플리케이션 스크립트는 포자 배경 애니메이션이며, 레벨·잠금 해제 로직은 포함되어 있지 않다. 따라서 이 지도 소스에서 잠금 표시나 CSS를 제거해도 부록 본문을 열 수 없다. 부록이 별도로 존재하는지와 그 URL은 이 페이지 소스로 확인할 수 없다.
