# Astra 버전과의 비교 · 채택 결과

`refer`의 실제 페이지 TSX, 최종 CSS와 이미지 파일을 조사하고 동일한 1280×900 및 390×844 뷰포트로 비교했다. 참고 화면은 원본 TSX의 마크업과 CSS를 별도의 읽기 전용 정적 화면으로 렌더링했다. `refer`의 서버·인증 스캐폴드를 실행하거나 수정하지 않았다.

## 비교와 적용

| 기준 | Astra 버전의 강점 | 기존 탐험 기록집의 강점 | 적용 결과 |
| --- | --- | --- | --- |
| 색과 분위기 | 네이비와 코퍼가 표지·강조의 위계를 분명히 만든다 | 아이보리 위 짙은 글자가 긴 학습 본문에 편하다 | 표지·상단 탐색은 네이비·코퍼, 본문은 아이보리 |
| 주차 목록 | 전체 테두리와 색상 선으로 카드의 클릭 범위가 명확하다 | ACT 소개와 주차 목록의 정렬, 학습 기록을 함께 제공한다 | 전체 테두리·ACT 색상 선·진행 표시를 결합 |
| 장 번호 | 큰 숫자가 현재 주차를 빠르게 식별하게 한다 | 원문의 장 제목과 진행 위치를 제공한다 | 주차 머리말에 큰 01–08 숫자와 CHAPTER 표시 |
| 모바일 ACT | 가로로 넓은 장면 이미지가 막 전환을 알려 준다 | 한글 제목을 단어 단위로 유지한다 | 넓은 ACT 이미지, 읽기 좋은 제목 줄바꿈, 명시적인 입장 표시 |
| 탐색 상태 | 첫·끝에서 이동 버튼이 비활성화된다 | 목차, 이어 보기, 키보드 탐색을 제공한다 | 첫 장 이전·마지막 장 다음을 비활성화하고, 다음 버튼을 우측에 배치 |
| 처음 진입 | 설명을 압축해 주차 선택까지 빠르게 도달한다 | 첫 방문 시작과 재방문 이어 보기를 구분한다 | 모바일 표지를 줄이고 ‘전체 지도 보기’ 바로가기를 제공 |
| 시각 자료 | 지도·작업 도구 소재가 탐험의 맥락을 만든다 | 새로 만든 배경·캐릭터 7개가 한 가지 화풍을 공유한다 | 새 일러스트의 통일감을 유지하고 프레임·코퍼 경계에 참고 |

모바일 합본의 첫 검토안에서는 첫 카드 시작점이 약 1029px이었다. 비교 후 표지·중복 통계·안내창을 압축해 약 821px로 앞당겼다. 같은 390px 폭에서 확인했으며, 상단의 ‘전체 지도 보기’를 누르면 주차 목록으로 바로 이동한다.

## 콘텐츠 기준

Astra의 `ArtifactPage.tsx`는 각 주차에 3개 예시 슬라이드를 선언하며, 표시되는 전체 장수는 19·14·16 등 별도 숫자를 사용한다. 전체 학습 콘텐츠와 실제 실습 동작의 기준은 이번에 확보한 원본 아티팩트다.

통합안은 8개 주차의 **217개 장면, 51개 퀴즈, 실습 체크·복사·확대·주문서 이동**을 유지한다. 원작자 표기 제거도 유지했다. 원본에 본문과 링크가 없는 최종 목표는 잠금 표시로 남겨 둔다.

## 확인 결과

- 본문 보존 검사: 217개 장면의 본문 해시 일치.
- 퀴즈 데이터 검사: 51개 문항의 정답·피드백 존재.
- 파일 검사: 실습 이미지 201개 참조가 로컬 파일로 연결.
- 8개 주차의 모든 장면: 320px·390px·1280px에서 가로 넘침 없음.
- 8개 주차: 첫 장 이전 버튼과 마지막 장 다음 버튼 비활성 확인.
- 기존 검수: 퀴즈 오답·정답 후 이동, 복사, 확대, 목차, 이어 보기 확인.

설명 이미지의 작은 글자는 OCR 재구성의 오인이 남을 수 있다. 완전 일치 검사는 HTML 본문에 적용했고, 복사 가능한 실습 주문서는 해당 본문을 사용한다.
